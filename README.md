# School Notes Hub — szervezeti profil

A [School Notes Hub GitHub-oldalán](https://github.com/school-notes-hub) megjelenő nyilvános bemutatkozás forrása: [profile/README.md](profile/README.md).

A profil magyar nyelvű, a projekt célját és nyilvános belépési pontjait mutatja be. A fejlesztés alatt álló szolgáltatásokat ennek megfelelően jelöli.

## Képek

- [Fejléc](profile/assets/header.jpg): a bemutatkozó oldalon használt, tömörített kép.
- [Avatar](profile/assets/avatar.png): 512 × 512 képpontos PNG, a szervezet profilképéhez.
- [Generálási promptok és fájladatok](docs/visual-assets.md).

A szervezeti avatar feltöltése a GitHub szervezeti Settings oldalán, az **Upload new picture** művelettel történik. A képfájl repóba feltöltése önmagában nem változtatja meg az avatart.

Ebben a repositoryban nincs tanulói forrásanyag, belső üzemeltetési dokumentáció vagy szervezetszintű alapértelmezett workflow. A bemutatkozás változtatásai Git-commitokkal követhetők.
